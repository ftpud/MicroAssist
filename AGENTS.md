# Agent Instructions

- Create a separate Git commit after every code update.
- Keep commit messages short and descriptive.

## Project Navigation

- `src/`: TypeScript server, assistant integration, scheduling, reminders, cards, and push delivery.
- `test/`: Server-side tests.
- `ios/MicroAssist/`: SwiftUI iPhone app.
- `ios/MicroAssistWidget/`: WidgetKit extension.
- `ios/Shared/`: Code shared by the app and widget.
- `workspace.example/`: Tracked template for the private runtime workspace.
- `dist/`: Generated JavaScript build output; do not edit directly.
